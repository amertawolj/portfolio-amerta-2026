## 😸 Amerta's So-Called-Portfolio

Hiii! Welcome to my first-ever portfolio project, or it definitely feels much more like a personal space

I wanted to break away from traditional layouts and build a retro-modern desktop environment right in the browser (with Windows XP x Mac x Frutiger Aero theme). It's a bit too fun to be called a "stuffy" professional portfolio, but it completely reflects my passions and aesthetic. 

The challenges I've faced so far are integrating the Spotify API to get the music player running, and tweaking this horizontal desktop layout into a clean mobile experience (which is still an active work-in-progress).

🌐 https://itsamerta.vercel.app/


## 🛠️ Built With

This project is built using Next.js because I love its file-based routing and clean project structure. For the visual styling, I used a blend of Tailwind CSS and Custom CSS to make the glassmorphism effects and widgets, all deployed and hosted on Vercel.
